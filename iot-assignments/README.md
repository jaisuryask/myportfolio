# IoT Assignments - Jai Surya S K

ESP32-based IoT tasks for the IoT assessment. The portfolio pages iot-task1.html to iot-task5.html in the parent folder document each task in detail.

| Task | Topic | Files |
|------|-------|-------|
| 1 | ESP32 web server and HTML LED control | see iot-task1.html |
| 2 | Adafruit IO dashboard and MQTT | task2_mqtt/task2_mqtt_bulb.ino |
| 3 | IFTTT with Adafruit IO, voice-controlled bulb | docs/IoT_Checklist_Gap_Fill_Tasks_2-5.docx (section 3) |
| 4 | Firebase IoT monitoring dashboard | docs/IoT_Checklist_Gap_Fill_Tasks_2-5.docx (section 4) |
| 5 | Firebase logging, automation and CSV export | task5_completion/task5_control_logic_snippet.ino, docs (section 5) |

Hardware: ESP32 Dev Module, relay module, bulb or LED, DHT11, LDR.
Software: Arduino IDE (ESP32 board package, Adafruit MQTT library, FirebaseClient), Firebase, Adafruit IO, IFTTT.

All credentials (Wi-Fi password, Adafruit IO key, Firebase keys) are placeholders. Fill in your own values before uploading and never commit real ones.

Demo videos: videos/task5 in the portfolio holds the Manual and Automatic mode clips.
